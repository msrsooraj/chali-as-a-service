# Chali as a Service

Your daily dose of Malayalam humour, one random chali at a time.

## How to Add Jokes

All jokes live in a single file: `chali.txt`. Each joke is separated by `---` on its own line.

### Single-line joke

Just write the joke as a single line:

```
Your joke goes here
```

### Multiline joke

Write each line of the joke on its own line:

```
Doctor: enthaa prashnam?
Patient: enikku vayaru onnu korakkanam
Doctor: Ujala kudikku
Patient: athenthina Ujala?
Doctor: Ujala kudichu kazhinja bluetooth indavum. And Bluetooth is wireless.
```

### Separating jokes

Always put `---` on its own line between jokes. Here's what `chali.txt` looks like:

```
First joke here
---
Line one of second joke
Line two of second joke
Punchline
---
Third joke here
```

### Steps to contribute

1. Fork the repo
2. Open `chali.txt`
3. Add `---` after the last joke
4. Add your joke below it
5. Submit a pull request

That's it. No config, no JSON, no database — just plain text.
