What is JSON?

JSON (JavaScript Object Notation) is a lightweight, text-based format for representing structured data — objects, arrays, strings, numbers, booleans, and null. It's the de facto format for web APIs, config files, and data interchange between systems, largely because it's both human-readable and easy for machines to parse.

Format vs. Minify

Format (pretty-print) adds indentation and line breaks so nested structures are easy to read — useful when debugging an API response or reviewing a config file. Minify strips all unnecessary whitespace, producing the smallest possible representation — useful when you're shipping JSON over the network and every byte counts, since whitespace adds up in large payloads.

Common JSON mistakes

  • Trailing commas — {"a": 1, "b": 2,} is invalid JSON (unlike JavaScript object literals, which tolerate this).
  • Single quotes — JSON requires double quotes for strings and keys; {'a': 1} will fail to parse.
  • Unquoted keys — {a: 1} is valid JavaScript but invalid JSON; keys must be quoted strings.
  • Comments — JSON has no comment syntax at all; // like this will break parsing.
  • Unescaped special characters — literal newlines or unescaped quotes inside a string value will produce a parse error.

This tool validates as it formats — if your JSON is invalid, you'll get a specific error message telling you what broke, instead of a silent failure.
