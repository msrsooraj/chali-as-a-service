What is Base64?

Base64 is an encoding scheme that converts binary or text data into a string made up of 64 printable ASCII characters (A-Z, a-z, 0-9, +, /). It exists because many systems — email, JSON, URLs — were designed to safely carry text, not arbitrary binary bytes. Encoding data as Base64 lets you embed images, files, or binary blobs inside text-based formats without corruption.

Common uses

  • Email attachments — MIME encodes attachments as Base64 so they survive transport through text-only mail servers.
  • Data URIs — embedding small images directly in HTML/CSS (data:image/png;base64,...) instead of a separate file request.
  • API tokens and auth headers — Basic Auth headers and many API keys are Base64-encoded strings.
  • Storing binary in text fields — databases or config files that only accept text can hold binary data this way.

Important: Base64 is not encryption

This is the most common misunderstanding. Base64 is encoding, not encryption — anyone can decode it instantly, with no key required (as you can see, this tool does it in your browser with zero setup). Never use Base64 alone to protect sensitive data like passwords or personal information. If you need actual security, use real encryption (AES, etc.) before encoding, or better, don't put sensitive data in a Base64 string at all.
