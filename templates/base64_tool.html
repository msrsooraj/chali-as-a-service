API

Encode or decode Base64 programmatically. Input is processed in memory and never logged or stored. Max 8000 characters per request — use the browser tool above for larger payloads (it never touches the server at all).

GET/api/base64/encode?text=...
GET/api/base64/decode?text=...

Example:

curl "{{ request.url_root.rstrip('/') }}{{ url_for('api_base64_encode') }}?text=hello%20world"
{ "result": "aGVsbG8gd29ybGQ=" }
curl "{{ request.url_root.rstrip('/') }}{{ url_for('api_base64_decode') }}?text=aGVsbG8gd29ybGQ="
{ "result": "hello world" }

Invalid input returns HTTP 400 with { "error": "..." }.
